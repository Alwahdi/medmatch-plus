# SyndeoCare Mobile (Expo)

تطبيق جوال للمختصين والمنشآت الصحية، يتصل بنفس الحسابات والبيانات المستخدمة في الموقع.

## التشغيل محلياً

```bash
cd mobile
npm install
npx expo start
```

ثم امسح رمز QR بتطبيق **Expo Go** على هاتفك (نفس شبكة الواي فاي)، أو اضغط `i` لمحاكي iOS و`a` لمحاكي أندرويد.

## الإعدادات

عنوان الخدمة السحابية والمفتاح العام موجودان في `app.json` ضمن `expo.extra`:

```json
"extra": {
  "supabaseUrl": "...",
  "supabasePublishableKey": "...",
  "webUrl": "..."
}
```

لا تضع أي مفاتيح سرية هنا؛ التطبيق يستخدم المفتاح العام فقط، والصلاحيات محمية في قاعدة البيانات.

## ما يتضمنه التطبيق

- تسجيل الدخول وإنشاء حساب (مختص أو منشأة) عبر نفس نظام الحسابات.
- تصفح الوظائف والمناوبات مع البحث والتصفية بالتخصص.
- التقديم على وظيفة وحجز مناوبة، مع نافذة الالتزامات والموافقة قبل الإرسال.
- نشاطي: الطلبات، المناوبات، الدعوات، والتقييمات المعلّقة.
- المحادثات والإشعارات.
- الملف الشخصي للمختص، ومساحة المنشأة لعرض الفرص والمتقدمين وتغيير مرحلة المتقدم.
- العربية أولاً مع دعم الإنجليزية وتبديل الاتجاه.

لوحة الإدارة والمهام المتقدمة (نشر فرصة جديدة، رفع المستندات، التوثيق) تبقى على الموقع.

## بناء تطبيق حقيقي (اختياري)

```bash
npm install -g eas-cli
eas login
eas build -p android --profile preview
eas build -p ios --profile preview
```

الإشعارات الفورية تتطلب بناءً حقيقياً؛ في Expo Go تعمل بقية الوظائف بشكل طبيعي.
