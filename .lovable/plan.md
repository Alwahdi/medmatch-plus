# خطة إكمال تطبيق SyndeoCare Mobile

## الهدف
تحويل تطبيق الجوال إلى تجربة إنتاجية متماسكة للمختص والمنشأة، مع إصلاح المسارات المكسورة، إكمال الوظائف الأساسية الموجودة في النظام، وتوحيد الواجهة والتفاعل بالعربية والإنجليزية.

## المرحلة 1 — الدخول والتجهيز الأولي
- توحيد إنشاء الحساب بالبريد وGoogle: اختيار الدور أولًا، حفظ نية الدور بصورة موثوقة، ثم المرور بنفس شاشة الترحيب.
- إنهاء حالة الحساب بلا دور: شرح سبب طلب الملف، ومنع تجاوزها، والانتقال تلقائيًا للرئيسية بعد إنشاء الملف ومنح الدور.
- دعم العودة إلى الوظيفة أو المناوبة الأصلية بعد تسجيل الدخول.
- إضافة حالات واضحة لتعثر تحميل الجلسة، الروابط غير الموجودة، والانقطاع.
- إصلاح تغيير اللغة واتجاه RTL/LTR مع إعادة تحميل آمنة وتنبيه واضح على الهاتف.

## المرحلة 2 — ملفات المختص والمنشأة والتوثيق
- إعادة تنظيم ملف المختص إلى بيانات أساسية، معلومات مهنية، التوفر والخصوصية، والتوثيق.
- إعادة تنظيم ملف المنشأة إلى الهوية، النوع، الموقع، وصف المنشأة، والتوثيق.
- ربط رفع مستندات التوثيق الخاصة بكل دور بالتخزين والجداول الحالية فقط، مع حالات الرفع والمراجعة والرفض وإعادة الرفع.
- إضافة شعار المنشأة وصورة المختص حيث تسمح البنية الحالية، دون كشفها قبل الوقت المسموح.
- استخدام المدن/الدول المتاحة بدل الحقول النصية الحرة عندما تتوفر البيانات.
- حماية التغييرات غير المحفوظة وإظهار نجاح الحفظ مؤقتًا.

## المرحلة 3 — رحلة المختص
- منع التقديم والحجز قبل اكتمال الملف، مع توجيه مباشر لإكمال الناقص.
- تحسين تفاصيل الوظائف والمناوبات: ترتيب المعلومات، حالة الفرصة، الخصوصية، والخطوة التالية بعد التقديم أو الحجز.
- إعادة تنظيم الاستكشاف والمرشحات والنتائج وحالات عدم وجود تطابق.
- إعادة تنظيم النشاط إلى طلبات، مناوبات، دعوات، مقابلات، وتقييمات بحالات واضحة.
- إضافة إدارة المقابلات المدعومة من النظام: عرض الدعوة والقبول والرفض وإعادة الجدولة والإلغاء حسب الصلاحية.
- توضيح أثر إعدادات الظهور للمؤسسات والتوفر للمناوبات.

## المرحلة 4 — رحلة المنشأة
- إزالة الطريق المسدود للمنشأة الجديدة وربط كل نقاط الإكمال بملف المنشأة.
- فصل الرئيسية عن إدارة الفرص لتجنب تكرار المحتوى والإجراءات.
- تحسين نشر الوظيفة والمناوبة: تحقق واضح، حقول مطلوبة، مراجعة كاملة، تحذير حالة التوثيق، وحدود الشواغر بلا تعديل صامت.
- بناء قائمة متقدمين آمنة تعرض التخصص والخبرة والمدينة والتوثيق وملخص التقييم دون كشف الهوية مبكرًا.
- إضافة ملف مرشح مختصر، دعوة واضحة، ومراسلة عند سماح مسار الخصوصية.
- تحويل إجراء المقابلة من تغيير حالة فقط إلى جدولة فعلية عبر الإجراءات الموثوقة الحالية.
- إضافة إدارة حجوزات المناوبات وحالاتها إلى نشاط المنشأة.

## المرحلة 5 — الرسائل والإشعارات والتنقل
- تحسين قائمة المحادثات، حالة الفراغ، عنوان المحادثة، القراءة، والإرسال المتفائل مع معالجة الفشل.
- جعل «تعليم الكل كمقروء» عملية واحدة واضحة بحالة تحميل ومنع التكرار.
- التحقق من الروابط العميقة حسب الدور وإظهار رسالة مفهومة عند عدم صلاحيتها.
- إضافة مؤشرات نشاط مناسبة لكل دور دون خلط الدعوات والتقييمات والمتقدمين.
- إزالة ازدواجية مساحة المنشأة وتثبيت غرض واضح لكل تبويب.

## المرحلة 6 — نظام التصميم والوصولية
- توحيد المسافات والطباعة والألوان والظلال والحواف من الرموز المركزية، وإزالة القيم البصرية المتفرقة.
- توحيد رؤوس الصفحات والبطاقات والقوائم والنماذج والأزرار والحالات الفارغة والخطأ والتحميل.
- الحفاظ على Cairo وهوية SyndeoCare وأيقونات Lucide، مع ألوان دلالية لا زخرفية.
- دعم النص الكبير، عناوين قارئ الشاشة، رسائل الحالة الحية، أهداف لمس 44px، ومساحات الأمان الفعلية.
- معالجة الشاشات الصغيرة 320/360/390/430 ومنع القص والتداخل والتمرير الأفقي.
- إضافة حركات قصيرة وظيفية فقط مع احترام تقليل الحركة.

## المرحلة 7 — التحقق النهائي
- فحص TypeScript واختبارات التصدير Android وiOS.
- اختبار رحلتي المختص والمنشأة من التسجيل حتى التوظيف/الحجز والمراسلة.
- اختبار العربية RTL والإنجليزية LTR، لوحة المفاتيح، النص الكبير، الانقطاع، الأخطاء، والروابط العميقة.
- اختبار 320 و360 و390 و430 و768، مع مراجعة بصرية لكل شاشة أساسية.
- عدم إضافة دفع أو بيانات وهمية، وعدم تغيير الخصوصية أو الصلاحيات لتجاوز الأخطاء، وعدم نشر التطبيق تلقائيًا.

## تفاصيل تقنية
- استخدام الجداول وRPCs وسياسات الوصول الحالية، وإضافة تغييرات قاعدة بيانات فقط عند وجود فجوة حقيقية وبأقل صلاحيات لازمة.
- رفع الوثائق إلى مسارات خاصة وربطها بسجلات التوثيق الحالية، دون روابط عامة.
- استخدام إجراءات المقابلات والدعوات والمراحل الموثوقة بدل تحديثات مباشرة تتجاوز دورة العمل.
- تقسيم التنفيذ إلى مكونات صغيرة ومراجعة كل مرحلة قبل الانتقال للمرحلة التالية.
