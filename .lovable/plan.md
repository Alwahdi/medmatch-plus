# تطبيق جوال SyndeoCare (Expo)

تطبيق جوال عربي/إنجليزي للمختصين والمنشآت، يعمل على نفس قاعدة البيانات والحسابات الحالية، داخل مجلد `mobile/` في نفس المشروع.

## المبدأ

التطبيق لا يعيد بناء المنطق: يتصل مباشرة بالخدمة السحابية الحالية بنفس الحسابات وقواعد الصلاحيات وسياسات الخصوصية. أي قاعدة عمل موجودة اليوم (التوثيق، إخفاء هوية المنشأة، الحصص، الموافقات) تبقى كما هي دون تعديل على الخلفية.

## ما يشمله التطبيق

**للمختص**
- تسجيل الدخول والتسجيل واستعادة كلمة المرور والتحقق بخطوتين
- إكمال الملف الشخصي والسيرة الذاتية والوثائق (رفع من الكاميرا أو الملفات)
- تصفح الوظائف والمناوبات مع الفلاتر والبحث والحفظ
- التقديم وحجز المناوبة مع نافذة الموافقة على الالتزامات
- طلباتي، مناوباتي، الدعوات، المقابلات، التقييمات
- المحادثات مع المرفقات والإشعارات

**للمنشأة**
- الملف والتوثيق ومستندات المنشأة
- نشر وإدارة الوظائف والمناوبات (تحرير، إغلاق، إعادة نشر)
- المتقدمون والحجوزات وتغيير الحالات والتوظيف
- بحث المرشحين والمرشحون المقترحون والدعوات
- المقابلات والمحادثات والتقييمات

**مشترك**: الإشعارات، مركز الحساب، اللغة العربية/الإنجليزية مع RTL كامل، الوضع الداكن، الصفحات القانونية وسجل الموافقات.

لوحة الإدارة تبقى على الويب فقط كما اتفقنا.

## نقاط يجب توضيحها الآن

- **Expo Go**: ممتاز للتجربة السريعة، لكنه لا يدعم إشعارات الدفع للأجهزة الحقيقية ولا بصمة/Face ID بشكل كامل. سأبني التطبيق بحيث تعمل هذه المزايا تلقائيًا عند الانتقال لاحقًا لبناء حقيقي، ومع Expo Go تظهر الإشعارات داخل التطبيق فقط.
- **استخراج السيرة الذاتية التلقائي** و**نموذج تواصل معنا** يعتمدان حاليًا على طبقة الويب؛ في الجوال سيتم رفع السيرة يدويًا مع تعبئة الحقول، وصفحة التواصل تعرض بيانات التواصل المحرَّرة من لوحة الإدارة.
- البريد والواتساب يبقيان معطّلين حتى توفير الاعتمادات، كما هو الوضع في الويب.

## الخطة التنفيذية

1. **الأساس**: مشروع Expo بأحدث إصدار داخل `mobile/` مع TypeScript وExpo Router وملف إعداد مستقل لا يتعارض مع بناء الويب.
2. **الاتصال بالخلفية**: عميل الخدمة السحابية بتخزين آمن للجلسة، وتحديث تلقائي للجلسة، ونفس أنواع قاعدة البيانات المولّدة.
3. **نظام التصميم**: ألوان وخطوط ومكوّنات (أزرار، حقول، بطاقات، حالات فارغة، هياكل تحميل) مطابقة لهوية الويب، مع RTL أصلي وأحجام لمس مناسبة.
4. **التنقل**: مسارات عامة (دخول/تصفح) ومسارات محمية مع تحويل حسب الدور: منشأة / مختص / إكمال التسجيل.
5. **الرحلات**: بناء الشاشات أعلاه بالترتيب — الدخول والملف، ثم التصفح والتقديم، ثم إدارة المنشأة، ثم المحادثات والإشعارات والتقييمات.
6. **الملفات**: التقاط من الكاميرا/المعرض واختيار المستندات مع نفس حدود الحجم والأنواع المطبقة في قاعدة البيانات.
7. **التحديث الحي**: الاشتراك في تغييرات المحادثات والإشعارات والطلبات مع تحديث احتياطي دوري، مثل الويب.
8. **ملفات النشر**: أيقونة التطبيق، شاشة البداية، معرّفات الحزمة لآبل وجوجل، الأذونات ونصوصها، وإعداد بناء جاهز للمتجرين.
9. **التشغيل عندك**: ملف README بخطوات واضحة (تنصيب، تشغيل، مسح الرمز بـ Expo Go)، مع تجربة الشاشات محليًا قبل التسليم.

## تفاصيل تقنية

- `mobile/` مشروع Expo مستقل (SDK الأحدث) بـ Expo Router، React Native، NativeWind للأنماط، TanStack Query للبيانات، `@supabase/supabase-js` مع `expo-secure-store` كمخزن جلسة.
- أنواع قاعدة البيانات تُنسخ من `src/integrations/supabase/types.ts` لضمان تطابق الاستعلامات والـ RPCs.
- تُعاد صياغة منطق المكتبات المشتركة (`legal`, `locations`, `match`, `notification-link`, `storage`, `listing-privacy`, `platform-settings`) كوحدات في `mobile/lib` بنفس القواعد.
- الوصول للبيانات عبر جداول وRPCs الحالية فقط؛ لا دوال خادمية جديدة ولا تعديل على السياسات أو الصلاحيات.
- I18n عبر قاموس محلي + `I18nManager` لضبط RTL، مع خط عربي مناسب.
- الإشعارات: `expo-notifications` مهيأة ومعطّلة تلقائيًا في Expo Go، وتسجيل الجهاز في جدول الاشتراكات يتم فقط في البناء الحقيقي.
- `eas.json` وملفات الأيقونات/الشاشة والأذونات جاهزة، دون تنفيذ أي بناء أو نشر تلقائي.
