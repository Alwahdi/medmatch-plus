# تحسين لوحة الإدارة: وجهة الأدمن، ضبط المستندات، وملف كامل لأي مستخدم

ثلاث حزم مترابطة، كلها داخل لوحة الإدارة عدا ما يظهر للمستخدم من متطلبات المستندات.

## 1) الأدمن يهبط في لوحة الإدارة لا في لوحة المختص

اليوم صفحة البداية بعد الدخول تحوّل صاحب المنشأة فقط، ولا تعرف الأدمن — فحسابك القديم كمختص صحي يفتح لك لوحة المختص.

- ترتيب الأولوية عند الدخول: أدمن ← منشأة ← مختص ← إكمال التسجيل.
- الأدمن يصل مباشرة إلى لوحة الإدارة، وإن كان له أيضاً ملف مختص أو منشأة يظهر في قائمة الحساب محوّل واضح «الانتقال إلى لوحة المختص / المنشأة» حتى لا يفقد حسابه القديم.
- رابط «لوحة الإدارة» يظهر في القائمة الرئيسية لصاحب الصلاحية بدل أن يُبحث عنه.

## 2) الأدمن يضبط المستندات المطلوبة

حالياً أنواع المستندات مكتوبة داخل الكود وثابتة (6 للكادر، 5 للمنشآت) والمطلوب منها محدد سلفاً. سننقلها إلى إعداد يديره الأدمن.

تبويب جديد «متطلبات المستندات» في لوحة الإدارة، بقائمتين: مستندات الكادر ومستندات المنشآت. لكل نوع مستند يضبط الأدمن:

- الاسم بالعربية والإنجليزية.
- مطلوب أم اختياري (المطلوب يشترط لمنح شارة التوثيق).
- عدد الملفات المطلوب لهذا النوع (مستند واحد أو أكثر) — الحد الأدنى.
- هل تاريخ الانتهاء مطلوب، وهل تاريخ الإصدار مطلوب، وهل جهة الإصدار مطلوبة.
- ملاحظة توضيحية تظهر للمستخدم تحت اسم المستند (مثال: «صورة واضحة للرخصة سارية»).
- ترتيب العرض، وتفعيل/إيقاف النوع (المخفي لا يظهر للمستخدمين الجدد ولا يؤثر على ما رُفع سابقاً).

أثر ذلك على المستخدم:
- قائمة «نوع المستند» في صفحة رفع مستندات الكادر والمنشأة تأتي من هذا الإعداد فقط.
- شريط «المستندات المطلوبة» ونسبة الاكتمال يُحسبان من الإعداد نفسه، مع بيان «مطلوب مستندان» حين يطلب النوع أكثر من ملف.
- الحقول تصبح إلزامية أو اختيارية حسب الإعداد، والتحقق يجري في الواجهة وفي قاعدة البيانات معاً.
- شارة التوثيق تُمنح عند اعتماد كل الأنواع المطلوبة المفعّلة.

## 3) ملف كامل لأي مستخدم من داخل لوحة الإدارة

أي اسم داخل لوحة الإدارة (طوابير المراجعة، طلبات التعديل، البلاغات، طلبات الحذف، رسائل التواصل) يصبح رابطاً يفتح صفحة ملف كامل للأدمن:

- أعلى الصفحة: الاسم والصورة والنوع (كادر/منشأة) وحالة التوثيق وتاريخ الانضمام، مع شريط إجراءات: اعتماد كل المستندات المعلّقة، منح/سحب التوثيق، فتح محادثة السجل.
- بطاقة «يحتاج إلى إجراء» في الأعلى: مستندات قيد المراجعة، مستندات مطلوبة لم تُرفع، مستندات منتهية أو تقترب من الانتهاء، طلبات تعديل معلّقة، بلاغات مفتوحة.
- البيانات الكاملة: التخصص، سنوات الخبرة، الموقع، النبذة، بيانات الرخصة، وسائل التواصل، التقييم المتوسط وعدد التقييمات — وللمنشأة: النوع، الموقع، الوصف، الموقع الإلكتروني، الاشتراك الحالي.
- المستندات: كل مستند بنوعه الرسمي واسم الملف وجهة الإصدار والتواريخ وحالته وأزرار عرض/اعتماد/رفض.
- سجل النشاط: عدد الوظائف/المناوبات المنشورة، الطلبات المقدَّمة، المناوبات المنجزة وساعاتها، المقابلات، التقييمات المستلمة، آخر ظهور.
- سجل تغييرات الملف والقرارات الإدارية السابقة.

## تفاصيل تقنية

- جدول `document_requirements` (target: professional/facility، code ثابت، name_ar/name_en، is_required، min_count، requires_expiry/issue_date/issuer، note_ar/note_en، sort_order، is_active) مع GRANT SELECT لـ authenticated و anon حسب الحاجة، و RLS للقراءة فقط؛ الكتابة عبر `admin_upsert_document_requirement` / `admin_delete_document_requirement` (SECURITY DEFINER + `require_admin_mfa()` + search_path مثبّت + EXECUTE محدّد). بذر الجدول بالقيم الحالية في نفس الـ migration حتى لا يتغير سلوك الحسابات القائمة.
- دوال احتساب التوثيق الحالية (`sync_facility_verification` ونظيرتها للكادر) تقرأ الأنواع المطلوبة من الجدول بدل الثوابت `FACILITY_REQUIRED_DOCS` / `PRO_REQUIRED_DOCS`.
- `src/lib/format.ts`: تبقى الثوابت كقيمة احتياطية فقط؛ الواجهات تستهلك hook جديد `useDocumentRequirements(target)`.
- التوجيه: `src/routes/_authenticated/dashboard.tsx` يضيف فرع `roles.includes("admin")` قبل فرع المنشأة، و`site-header` / `account-hub` يعرضان رابط لوحة الإدارة والمحوّلات.
- صفحة جديدة `src/routes/_authenticated/admin.users.$userId.tsx` تقرأ عبر server function محمية بـ `requireSupabaseAuth` + تحقق دور الأدمن و MFA، وتجمّع البيانات بدالة `admin_user_overview(_user_id)` واحدة (SECURITY DEFINER) لتفادي عشرات الاستعلامات.
- `admin-review-queue.tsx` وبقية جداول الأدمن: الاسم يصبح `Link` إلى الصفحة الجديدة؛ لا تغيير في منطق الاعتماد الحالي.
- الحفاظ على القواعد: لا بيانات وهمية، الرسائل عربية أولاً مع RTL سليم، وأخطاء قاعدة البيانات لا تظهر خاماً.
